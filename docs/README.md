# Documentation

The model, its derivations and the results are presented in the paper
*"Geometry-controlled active transport in smectic textures"*.

[`abp-smectic.excalidraw`](abp-smectic.excalidraw) gives a one-page overview:

1. the three smectic textures (flat, fcd, tfcd);
2. the swimmer dynamics (self-propulsion Pe, alignment torque ε, rotational noise);
3. the path from a configuration file to the output data;
4. the reference times of the observables (MSD after relaxation to t = 100, RMSD from t = 0).

Open it at [excalidraw.com](https://excalidraw.com) or with the Excalidraw extension for VS Code.
